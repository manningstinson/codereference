## How to Install

If git is not already installed on your terminal:

``` $ sudo apt-get update
$ sudo apt-get upgrade
$ sudo apt-get install git
```

## Commonly Used

| #  | Command              | Function                               |
|----|----------------------|----------------------------------------|
| 1  | `git init`           | Initialize a Git repository            |
| 2  | `git clone`          | Clone a repository                     |
| 3  | `git status`         | Show the working tree status           |
| 4  | `git add`            | Add files to the staging area          |
| 5  | `git commit -m`      | Commit changes with a message          |
| 6  | `git push`           | Push changes to the remote repository  |
| 7  | `git pull`           | Fetch and merge changes from the remote repository |
| 8  | `git branch`         | List, create, or delete branches       |
| 9  | `git checkout`       | Switch branches or restore working tree files |
| 10 | `git merge`          | Merge branches                         |
| 11 | `git log`            | View commit history                    |
| 12 | `git stash`          | Stash changes temporarily              |
| 13 | `git rebase`         | Reapply commits on top of another base tip |
| 14 | `git diff`           | Show changes between commits, commit and working tree |
| 15 | `git reset`          | Reset the current HEAD to a specified state |
| 16 | `git remote`         | Manage remote repositories             |
| 17 | `git tag`            | Tag a specific commit                  |
| 18 | `git blame`          | Show who modified each line of a file  |
